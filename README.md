# Workout Planner

A full-body workout builder for women. Pick your level, goal, time, equipment and emphasis, and it builds a warm-up, a main workout and a cool-down.

## Features

- **Settings:** Beginner / Intermediate / Advanced; Strength, Tone & sculpt or Fat burn; 20, 30 or 45 minutes
- **Equipment (pick any):** dumbbells, kettlebell, barbell & bench, cable machine, machines (leg press, lat pulldown, rower). Bodyweight moves are always included.
- **Emphasis (pick any):** Glutes & legs, Arms & back, Core, Cardio, or Balanced
- **47 exercises,** each with an animated demo, sets / reps / rest, a form cue, and the exact primary and secondary muscles worked
- **Session coverage:** a list of every primary muscle the workout hits
- Swap any move, mark moves done, and copy the whole plan as text

## Use it

It's a single self-contained file. Open `index.html` in any browser, or turn on GitHub Pages (Settings → Pages → deploy from the `main` branch) to get a shareable link.

> If you're pregnant, postpartum, or working around an injury, check with your provider before starting.
